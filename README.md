# LOLauncher

An unofficial, lightweight launcher for **Last Origin R+**.

LOLauncher is built to replace the heavier VFUN launcher experience with a smaller, faster, game-focused launcher. It handles game detection, installation, patching, repair, uninstall, VFUN login, game launch, news, settings, tray behavior, and launcher self-updates.

## Highlights

- Lightweight launcher focused only on Last Origin R+.
- Around 2x smaller than the official VFUN launcher.
- Faster game downloads and patching.
- Multi-threaded patch extraction for faster file application.
- Install, update, repair, uninstall, and launch flows.
- VFUN ID, Google, Facebook, and Apple login support.
- OTP support for accounts that require verification.
- Encrypted remembered login storage.
- News carousel with official game news.
- System tray behavior and optional startup on Windows login.
- Launcher self-update support with optional and mandatory updates.
